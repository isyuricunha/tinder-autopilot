Your rules for
Tinder Web.

Tinder Autopilot is an open-source browser extension that applies your profile filters, automates swipes, and sends your first-message template from a sidebar in Tinder Web.

Download extension ↓ Installation guide ↗

Chrome · Brave · Firefox · Desktop

01 The controls

You set the rules. Autopilot applies them.

↗

Auto swipe with filters

Set an age range, distance limit, minimum photo count, and blocked bio terms. Add your own profile rules if you configure a model provider.

✦

Personalize first messages

Write an opener with {name} for matches with empty conversations. Limit it to new matches or preview a contextual reply before sending.

≡

See what happened

Check swipe totals, decision reasons, and step timings in Activity. If automation pauses, the sidebar tells you what stopped it.

02 Getting started

Install it on
your browser.

Download the ZIP for your browser from GitHub Releases and extract it before loading the extension.

Get the latest release ↗

  1. Chrome or Brave

    Open chrome://extensions or brave://extensions. Enable Developer mode, choose Load unpacked, and select the extracted Chromium folder.

  2. Firefox

    Open about:debugging#/runtime/this-firefox. Choose Load Temporary Add-on and select the extracted manifest.json. Load it again after restarting Firefox.

  3. Open Tinder Web

    Sign in at Tinder Web and open Recommendations. The Autopilot sidebar appears on the left.

03 Questions

Good to know.

Does Tinder Autopilot work on mobile?

It runs on Tinder Web in Chrome, Brave, or Firefox on desktop. It requires a signed-in Tinder Web session.

Do I need a model provider or an API key?

Basic swipes, built-in filters, and template messages work without one. Custom model-based profile rules and contextual replies require a configured provider.

Can I preview a reply before sending it?

Yes. In Messages, open Test Replies to inspect the prompt or generate a preview. Reply once and Continuous can send real messages.

Where are my settings and data stored?

Preferences and counters are stored in your browser, and provider keys in extension storage. When you use model-based filtering or replies, relevant profile or conversation context goes to your configured provider.

Is Tinder Autopilot affiliated with Tinder?

It is an independent open-source project. Tinder is a trademark of its respective owner.
